📨 AI 电机命令 (Modbus RTU)

前缀 B1 = 左臂, B2 = 右臂 · 所有命令以 \r\n 结尾

🎯 位置控制

B1 M1 P10000 S300

B1=左臂, M1=电机1(X轴), P=位置(脉冲), S=速度(rpm)

参数范围单位说明
P (position)-9999999 ~ 9999999脉冲负数=反向
S (speed)0 ~ 6000rpm默认300

🔍 查询位置

B1 M1 Q
POS B1 M1 12345

返回当前位置(脉冲)

⚡ 使能

B1 M1 EN
ERR: single-axis EN disabled, use ALL ENABLE

单轴使能已禁用；使用二进制全局 ENABLE

🛑 停止

B1 STOP
OK STOP: ACCEPTED

全局停止双臂 12 轴；B1 仅兼容保留

🏠 回零

B1 M1 HOME
OK B1 M1 HOME

电机归零位

🔌 测试

B1 TEST
ERR B TEST DISABLED: use binary ENABLE

危险的直通 Servo On 测试入口已禁用

⚠ 急停

ALL STOP
OK STOP: ACCEPTED

双臂 12 轴全局安全停止

📨 慕纬度电机命令 (私有协议 0x3E)

前缀 L = 左臂, R = 右臂 · 角度制

🎯 关节角度控制 (带耦合解算)

L J5 30 J6 45 S180
OK L J5=30 J6=45 S=180
参数范围单位
J5-36000 ~ 36000度 (°)
J6-36000 ~ 36000度 (°)
S (speed)1 ~ 36000°/s
J5/J6 有机械耦合，MCU 内部自动解算为电机目标值

🔍 查询角度

L Q
POS L J5=30 J6=45

返回解算后的关节角度(度)

🛑 停止 / 🏠 回零

L STOP
L HOME

📊 JavaScript 接口示例

// 使用 Web Serial API (Chrome/Edge)
const port   = await navigator.serial.requestPort();
await port.open({ baudRate: 115200 });
const writer = port.writable.getWriter();
const reader = port.readable.getReader();

// 发送命令
function send(cmd) {
  const enc = new TextEncoder();
  writer.write(enc.encode(cmd + '\r\n'));
}

// 读取回复
async function readLine() {
  let buf = '';
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buf += new TextDecoder().decode(value);
    const i = buf.indexOf('\n');
    if (i >= 0) return buf.slice(0, i).trim();
  }
}

// 控制左臂 X 轴运动
await send('B1 M1 P10000 S300');      // X轴右移
await send('B1 M1 Q');                // 查询位置
await send('B1 STOP');                // 停止

// 控制左臂关节
await send('L J5 30 J6 45 S180');    // J5=30° J6=45° 速度180°/s
await send('L Q');                    // 查询角度

⚠ 调试命令（问题排查用）

命令用途
B2 TEST给右臂3个电机全发使能，测试RS485总线是否通
B2 M1 EN单独使能右臂电机1，排查站号问题
B2 M2 EN单独使能右臂电机2
B2 M3 EN单独使能右臂电机3
B2 M1 Q读电机1位置，确认双向通信

如果 LED 闪但电机不响应：检查波特率（CPP代码用57600/你的电机可能是57600）、接线交叉、站号
